# Поиск уязвимостей продуктов

Консольная утилита на Python 3 и SQLite для анализа фида версий продуктов и фида известных уязвимостей. Сторонние Python-библиотеки не нужны.

## Файлы

- `main.py` — консольный интерфейс и импорт фидов.
- `schema.sql` — схема SQLite.
- `versions.json` — фид производителя, продукта и версии.
- `vulnerabilities.json` — фид уязвимостей.
- `vulnerabilities.db` — создаётся локально командой импорта; в Git не хранится.

## Запуск

Поместите оба JSON-фида рядом с `main.py`, затем выполните:

```bash
python main.py --init
python main.py --list
python main.py safe "Git for Windows"
python main.py vulns "Git for Windows" "2.38.0"
```

## Структура БД

Исходные строки сохраняются в `feed_versions_raw` и `feed_vulnerabilities_raw`, включая дубликаты и исходный JSON. Нормализованные таблицы: `vendors`, `products`, `product_versions`, `vulnerabilities`. Внешние ключи связывают производителя с продуктом, а продукт — с версиями и уязвимостями.

## Важное ограничение

Сопоставление уязвимых версий основано на структуре предоставленного фида: версия считается затронутой, если она ниже `fixed_version` и соответствует основной ветке `start_vuln_version` (значение `0` трактуется как отсутствие ограничения). Это эвристика, а не гарантия безопасности: перед промышленным применением необходимо подтвердить семантику полей у поставщика фида.
